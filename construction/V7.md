# Estimate v7

V7 adds labour/material evidence tables, selected-item component charts and an optional temporary NPR component calculator to the v6 estimate. All earlier versions and original rates/amounts remain intact.

See [public status](../public/construction/estimates/pilates-astra-2026-10-15/v7/status.md) for evidence coverage, source archive, validation and remaining external/input debt.

The reproducible register generator is `construction/estimates/pilates-astra-2026-10-15/research/build-components.py`. It preserves unknown original allocations, distinct material/installation/combined bases, daily wages and exact SI factors. It creates no accepted quote split.

Validation: `npm run check` (40 passing tests and static build), plus built-page local link and imported-module path checks. The Sites environment has no supported browser QA surface.
