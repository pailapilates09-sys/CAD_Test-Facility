04 / LEARN THE TOOLS

What code draws a website?

Use each tool for the job it does well.

HTML

The page structure.

Creates headings, buttons, tables, links and the drawing workspace. It gives the site its content and meaning.

CSS

The visual design.

Controls colours, spacing, typography and responsive layouts. It keeps the drawings usable on a phone and a desktop.

JavaScript / TypeScript

The behaviour.

JavaScript runs the controls and calculations. TypeScript adds type checks before compiling to JavaScript; it is useful as the product catalogue grows.

SVG

The 2D drawing.

Stores lines, arrows, labels and shapes as vectors. It stays sharp when zoomed and can be downloaded for further editing.

THREE.JS

The 3D model.

Turns dimensions into meshes, adds lights and cameras, and lets you rotate, inspect or separate the parts in your browser.

JSON + GITHUB ACTIONS

The source & publishing.

Shared dimensions feed both views. GitHub Actions builds the files and GitHub Pages serves the finished site. Drive stores the compiled drawings and release packages.
