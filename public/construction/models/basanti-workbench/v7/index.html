Water demand, pressure and pump duty

Hazen–Williams: hf = 10.67 L Q^1.852 / (C^1.852 D^4.87), SI Q in m³/s and D in m. V = Q/A. Equivalent length = 1.3 × routed length. The unknown tank approach, meters, valves and pump suction conditions still need a measured-site loss calculation. NBC208 pressure-unit discrepancy is recorded as I03.

Roof catchments, rainfall and drain sizing

Q (L/s) = i (mm/h) × effective area (m²) × runoff coefficient / 3600. Conservative envelope areas split into disjoint zones; 50% of scenario parapet wall area is added. NBC208 C3 gives 62.7 m² per 150 mm pipe at 200 mm/h. Other intensities use stated constant-flow scaling. Outlet inlet capacity, waterproofing, emergency overflow and safe discharge need separate checks.

Gravity drainage falls and capacity

V = R^(2/3) S^(1/2) / n; R = D/4 for a circular pipe half full; Q = half circular area × V. n = 0.015 follows NBC208 B15. A half-full capacity is not proof of self-cleansing at every small intermittent flow. Final fixture discharge, rodding, trap seals and vents also govern.

Electrical loads, circuit protection and cable checks

Ib = P/(230 × PF); screen Ib ≤ In ≤ Iz × derating. Voltage-drop screen uses 2ρLI/A at ρ = 0.0225 Ω mm²/m, feeder plus longest point path and 3 m termination allowance. This conservative resistive-loop study excludes reactance, motor start, fault-loop / adiabatic checks and harmonic-neutral analysis. 3% lighting / 5% other targets are supplementary IEC guidance. Verify actual product dimensions for conduit fill, including extra switch/control conductors.

Mechanical extract and equipment schedule

15 L/s bathroom / 30 L/s ducted hood are supplementary engineering targets from England’s Approved Document F. NBC206 natural-opening review remains separate. No AC cooling capacity, refrigerant diameter or fan pressure is invented.

How to update one page in a multi-page website

Developers call this a scoped feature change. A page is a URL; its HTML, scripts, CSS, shared data, build code and navigation form a dependency graph. We change the smallest set of owners that produces the requested result, then check dependent pages.

This branch is named work/14-basanti-poudel-baral-v7-mep-2026-10-29. V7 owns its MEP modules and scoped styles. V6 stays at its existing address; unrelated project code is inherited through Git history, not copied into new editable folders.
  1. Start a named branch from current main. Git records the complete repository state and tracks only the changed files.
  2. List the change scope. Here: new v7 folder, one build entry, version manifest and the hub entry. Earlier model/estimate data stays with its existing owner.
  3. Keep one data source. Plans, 3D, tables, calculations and Gantt read the same MEP model. Do not hand-edit five separate copies of a quantity.
  4. Scope the CSS and modules. The .mep-page selector limits this page’s styling. Changing shared CSS or source data can affect siblings and needs broader regression checks.
  5. Review the pull request’s Files changed tab. Compare the file list to the intended scope, then inspect the line diff, generated drawings, calculation assumptions and preview.
  6. Run tests and a full build. Targeted math checks verify this feature; full link/build checks catch shared-navigation or sibling regressions. Phone-width, keyboard and theme checks cover the page experience.
  7. Merge and publish. This repository’s Actions checks a PR; a merge/push to main builds and deploys the Pages site. Rebuilding the entire site does not mean every page’s source was edited.
  8. Keep a rollback boundary. Record the exact commit. A Git revert can undo this feature; historical version URLs remain stable. A branch is a development line; v7 is a user-facing product version.
