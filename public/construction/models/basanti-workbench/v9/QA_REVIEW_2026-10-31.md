# Basanti v9 · user QA

**31 October 2026 · VERIFIED WITH LIMITS**

V9 improves the review interface. It reuses v8 quantities and programmes, the v6 structural interpretation and v7 MEP coordinates. Earlier versions remain available.

| Finding | V9 behavior |
| --- | --- |
| V8 MEP has no drag handler despite its orbit instruction | MEP uses the same interactive 3D viewer as the other disciplines. Drag and keyboard rotation were observed to change projection; dragging preserves selection. |
| All-floor plan can disagree with selected route | The default selection prefers Ground; selecting a First-floor route changes the plan to First. Explicit floor filters retain their stated scope. |
| Floor labels overlap in top or steep camera views | Labels are spaced inside the viewport with leader lines to their original positions; off-screen anchors are omitted. |
| Service routes are hard to separate | Named MEP route-service filter, service colours, selected-route details and a visible filter summary. |
| A mobile Floor dropdown became too narrow | Floor uses a full row when the service filter is hidden. Checked at 320–1280 CSS pixels. |
| BOQ details are distant and bookmarks lose their table page | Selecting an item scrolls/focuses its evidence. A bookmarked item restores its page. Unit and work-name/quantity order controls are provided. |
| Gantt updates lose chart position or group state | Open groups and chart scroll are retained. Selecting M23 retained 1712 px of chart scroll. Predecessors and exact related BOQ records remain linked. |
| A generated extra TOC duplicates the five tabs | V9 keeps Overview, Views, BOQ, Gantt and Sources as its single pinned panel navigation. Legacy contents remain grouped. The ten-project comparison retains its stable anchor inside the shared footer. |
| SVG forced downloads are difficult to inspect | Open full chart opens the complete HTTP SVG in another tab. Open SVG opens the current plan preview; CSV remains a download. The cloud browser limit on plan-preview inspection is recorded below. |
| Readers can click before startup handlers are ready | Main workspace controls remain disabled until data and handlers are ready. Load errors provide previous-workspace and source-PDF links. |

## Verification

- 373 automated tests passed; 144 HTML pages, 10,461 local links/assets and 257 module imports passed the build checks.
- IFC export: 0 schema errors. Source checkpoint CP539 and extraction controls remain valid.
- Browser checks: drag and keyboard orbit; selection; presets; focus/isolate/context; service/floor/search filters; empty results; optional steel; BOQ basis/unit/order, detail focus, pagination and bookmarked items; activity/BOQ links; both schedules; tab keys/Home/End; browser Back; light/dark.
- 40 v9 layout cases across 320, 375, 430, 768 and 1280 CSS-pixel widths; 18 preserved-view layout cases across 320, 768 and 1280. No unintended page overflow was found.
- Filtered CSV downloaded and was compared with source JSON: both matching quantities retain full precision. The MEP full-chart SVG opened over HTTP and had finite geometry, 37 text labels and a 2000-pixel height.

## Data preservation

- All 143 previous page addresses and all 377 prior Basanti files remain. No original section IDs or table counts were lost.
- 363 Basanti files are byte-identical. Changes to prior files are presentation HTML plus the version directory; all prior non-HTML Basanti files, except the appended version manifest, are byte-identical.
- V9 has the same 221 BOQ records, 745 measurement lines, 112 building activities and 23 MEP activities as v8. Building uses 241 calendar days; MEP uses a separate 37-workday basis.
- All seven retained BOQ/evidence/programme/steel exports are byte-identical between v8 and v9. Pending values remain null. No rates, furniture schedule, quantities, dates or approvals were invented.
- Source PDF SHA-256: `a951721f046d4321542ae0c6b386c9a54b5575bc4c0676544daaff98a9e77611`.

## Verification limits

- Cloud browser blocks inspecting blob: URLs. The generated plan preview tab was observed to open with its expected title, but its separate contents were not inspected. Inline plan selection/floor behavior was checked.
- 3D rendering was verified in interactive vector fallback. Hardware WebGL and context-loss recovery were not exercised in this browser.
- Phone/tablet widths were checked in browser viewports; physical touch devices were not tested.
- Existing source contradictions, engineering approval gates, proposed furniture and unpriced quantities remain unchanged.
